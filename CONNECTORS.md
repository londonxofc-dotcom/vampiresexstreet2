# Connectors

## Brand context

This plugin is customized for **Vampire Sex** — minimal tech house DJ duo, Miami FL. Label: Sex Sells Records. Site: vampiresex.com.

**Brand voice:** respectfully disrespectful. Terse. ALL CAPS where it counts. Occult-meets-luxury aesthetic ("BLOODLINE", "VOID COVENANT", "PARISH CLOAK"). No filler. Edition-numbered drops, limited runs, proof on request. Streaming proof. Club proof.

**Audience:** electronic music fans, working DJs (sells DJ tools like Hex Venom USB), collectors (limited 50-unit physical drops), event promoters (booking inquiries).

**Distribution channels:** Spotify, Apple Music, Beatport, Traxsource, Instagram, vampiresex.com (registry / offer flows / merch), email via Resend.

## Connected tools

| Use | Tool |

| Streaming analytics (Spotify) | Spotify for Artists |

## Tools intentionally not used

Marketing automation, dedicated email marketing platform (Klaviyo / Mailchimp), SEO tools (Ahrefs / Semrush), knowledge base (Notion / Confluence), design SaaS (Canva / Figma) — skipped per user. If you decide to add one later, re-run the plugin customizer.
