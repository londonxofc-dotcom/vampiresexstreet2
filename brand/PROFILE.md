# Vampire Sex — Brand Profile

> Every skill in this plugin should reference this profile. When drafting content, planning campaigns, or reviewing copy, default to these values unless the user overrides them in the prompt.

## Identity
- **Name:** Vampire Sex
- **Type:** Minimal tech house DJ duo
- **Base:** Miami, FL
- **Label:** Sex Sells Records (Sex Sells Rec.)
- **Site:** https://vampiresex.com

## Voice
- **One-liner:** Respectfully disrespectful.
- **Tone:** Terse, cryptic, confident. Occult-luxury hybrid. Reads like a velvet-rope flyer, not a press release.
- **Format conventions:**
  - ALL CAPS for headlines, drop names, and CTAs
  - Short, declarative sentences. Periods over commas.
  - "No filler." "Streaming proof. Club proof." "No restock. No exceptions."
  - Edition numbering when relevant (ED. 001/050)
- **Avoid:** corporate hype words (synergy, leverage, unlock), exclamation points, emoji, friendly customer-service tone.

## Audience segments
- **Fans / streamers** — discover via Spotify, Apple Music, Beatport, Traxsource, Instagram
- **DJs** — buy tools (Hex Venom USB), source unreleased
- **Collectors** — limited physical drops (Crimson Relic Tee, Void Covenant Hoodie, Parish Cloak Jacket, Nocturne Crown Snapback), edition-numbered, proof on request
- **Promoters / venues** — booking inquiries via offer form

## Channels
- **Streaming:** Spotify, Apple Music, Beatport, Traxsource
- **Social:** Instagram (primary)
- **Owned:** vampiresex.com — Bloodline registry (early access list), Make-an-Offer flow, merch drops, EPK
- **Email:** Resend (transactional + drop announcements)

## Analytics stack
- **Spotify for Artists** — Spotify streams, listeners, playlists, geo
- **Apple Music for Artists** — Apple plays, Shazams, geo
- **Songstats** — cross-platform aggregate, charts, playlist tracking, comparisons

When generating performance reports, pull from these three. Do not assume Google Analytics or Mixpanel.
